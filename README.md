## About me

I connect field research, data analysis and practical software. My academic work focuses on agricultural extension, fisheries and rural livelihoods in Bangladesh. On GitHub, I build tools for everyday finances, small businesses and students.

- **Research:** agricultural resilience, technology adoption and extension systems.
- **Building:** Hishab, a personal finance app for web and Android.
- **Approach:** clear interfaces and tools that solve everyday problems.
- **DigitXBD:** the name behind my app work.
